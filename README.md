# E-Commerce Platform

A Laravel-based E-Commerce web application built to practice and implement real-world backend development concepts.

## Features

- Authentication & User Management
- Shopping Cart
- Wishlist
- Product & Category Management
- CRUD Operations
- Form Validation
- Laravel Migrations & Eloquent Models
- Database Relationships
- AJAX Interactions
- Admin Dashboard

## Technologies

- PHP
- Laravel
- MySQL
- JavaScript
- jQuery / AJAX
- Bootstrap
- Blade

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_NAME
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan storage:link
php artisan serve
